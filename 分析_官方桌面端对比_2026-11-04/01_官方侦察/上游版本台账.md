## 1. 一句话结论

- 官方桌面端**没有独立版本号体系**：它跟随 `@deepseek-ai/dsh` 的版本，tag 形如 `dsh-v<version>`，**不存在 `desktop-v*`**。
- **至今没有任何正式版（stable）**：36 个 release 全部 `prerelease`，所有 `stable*.yml` 清单返回 404。
- 线上实际可安装的 Windows/macOS 桌面版是 **`0.2.1-rc.5`**（2026-10-29 发布），比源码树的 `0.2.2-alpha.3` 落后一个 alpha 线。
- 桌面端**不发 npm**（`private: true`，registry 返回 404）；只通过 `download.deepseek.com` 的腾讯云 COS 分发安装包。
- GitHub Release **不含任何安装包**（36 个 release 的 `assets` 全为 0），仅作版本记录与打 tag 用途。

## 5. 渠道（channel）台账

| 渠道 | 清单文件 | 清单里允许的版本形态 | 客户端 `allowPrerelease` | `allowDowngrade` | 当前线上状态 |
|---|---|---|---|---|---|
| `nightly` | `nightly.yml`（Win）/ `nightly-mac.yml`（mac） | 任意合法 semver（含 `-rc.5`） | `true` | `false` | ✅ 有产物 |
| `stable` | `stable.yml` / `stable-mac.yml` | **必须无预发布后缀** | `false` | `false` | ❌ 404，从未发布 |

**渠道来源**：安装包 `package.json` 的 `dshDesktopUpdateChannel` 字段（`apps/desktop/scripts/electron-builder-config.mjs:115` 写入，`apps/desktop/src/update-channel.ts:14-17` 读取；缺省 = `nightly`，非法值 = 抛错）。
**渠道切换**：设置页 → 落盘 `userData/desktop/settings.json` 的 `updates.channel`，立即通过 IPC 生效（`README.zh.md#local-desktop-settings`）。
**渠道更名史**：`latest` → `stable`，发生在 `0.2.2-alpha.2`，**不提供别名**，旧包仍请求 `latest` 清单的不会自动迁移：

> 「桌面安装包、更新清单及渠道配置使用 `stable`，不再使用 `latest`。`nightly` 渠道不变。旧渠道值会被拒绝，不提供别名。网站名为 `dsh-latest-*` 的固定下载文件保持不变。」
> —— `docs/upgrade-guide/v0.2.2-alpha.2/desktop-stable-channel/guide.zh.md:12`

**两级"stable 拒预发布"防护**：
1. 打包期：`electron-builder-config.mjs:108` 抛错
2. 运行期：`update-coordinator.ts:279` 抛错 `desktop update: stable feed contains a prerelease`

## 9. 台账更新方式

本文件的三个数据源都可无凭据复现：

```powershell
# 1) 线上清单（版本 + 体积 + sha512 + releaseDate 的唯一权威）
Invoke-WebRequest "https://download.deepseek.com/dsh-desk/feeds/win-x64/nightly.yml" -UseBasicParsing

# 2) GitHub Release 序列
Invoke-RestMethod "https://api.github.com/repos/deepseek-ai/deepseek-harness/releases?per_page=100" `
  -Headers @{ 'User-Agent'='dsh-recon' }

# 3) npm dist-tags
Invoke-RestMethod "https://registry.npmjs.org/@deepseek-ai%2Fdsh"
```

⚠️ GitHub API 匿名限流 60 次/小时；`per_page=100` 一次即可拿全 36 条，**不要逐 tag 拉取**（本次为抽查 release notes 额外消耗了 6 次）。
