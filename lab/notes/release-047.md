## 0.3.47：桌面报告只留一份，历史归档到安装目录并定期清除

### 现场

桌面上堆了 **7 份** `DSH-Desktop-错误报告-<时间戳>.txt`（2026-10-19 一天就 5 份，其中一份 84KB）—— 排查时根本分不清哪份是当前的。

根因：桌面报告的文件名带时间戳，而报告是**每次启动新建一个、从不清理**的。

```
C:\Users\lcl\Desktop\
  DSH-Desktop-错误报告-2026-10-19-063631.txt    59.4 KB
  DSH-Desktop-错误报告-2026-10-19-175100.txt    10.5 KB
  DSH-Desktop-错误报告-2026-10-19-183329.txt     8.3 KB
  DSH-Desktop-错误报告-2026-10-19-192527.txt     8.0 KB
  DSH-Desktop-错误报告-2026-10-19-195101.txt     8.1 KB
  DSH-Desktop-错误报告-2026-10-19-200522.txt    84.2 KB
  DSH-Desktop-错误报告-2026-10-20-115940.txt     8.8 KB
```

### 新纪律

| | 旧 | 新 |
|---|---|---|
| 桌面 | 每次启动一份，永久堆积 | **固定名 `DSH-Desktop-错误报告.txt`，永远只有一份**（当前这次启动的） |
| 历史 | 留在桌面 | 归档到**安装目录** `logs\DSH-Desktop-错误报告-<时间戳>.txt` |
| 清除 | 无 | 归档按**份数（10）+ 天数（30 天）**双上限定期清除（与主日志/错误清单同一套纪律） |

- 归档动作发生在**每次启动的第一条日志**上：上一轮的那份 + 0.3.46 之前遗留在桌面上的时间戳名报告，一并搬进安装目录
- 写报告头用**覆盖**语义（本次启动从头开始），不再 append 到上一轮的残留上
- 桌面上的**非 DSH 文件永不触碰**（只认 `DSH-Desktop-错误报告*` 这一族命名）
- 清除只删**文件名里带可解析时间戳**的我方归档 —— 改名过/外部文件一律不动（同 P2-2 纪律）
- 清除时机：每次启动 + 每 24 小时一次（沿用主日志的 housekeep 节奏）

### 现场已清理
