① 应用内安装（推荐，永不装错）

用桌面版自带的 Node + dsh 入口执行 plugin add，DSH_HOME 天然正确。无需安装 CLI、无需碰终端。

② 终端包装器

生成 dsh-desktop.cmd / dsh.cmd / dsh-desktop.ps1，脚本内固定 DSH_HOME 并调用桌面版 Node。追加在 PATH 末尾，不抢占你已有的全局 dsh。
